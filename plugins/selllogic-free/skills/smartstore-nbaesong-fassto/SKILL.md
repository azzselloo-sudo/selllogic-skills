# 스마트스토어 N배송 + 파스토 셋업

파스토 공식 가이드 = guide-kr.fassto.ai/nfa/linkage. 이 문서는 그 가이드에 실제로 막히는 지점을 더한 것이다.

## 0. 먼저 알아 둘 것

N배송은 **세 개가 모두 켜져야** 동작한다. 하나만 빠져도 증상이 다르게 나서, 한 곳만 보고 "원인을 찾았다"고 하면 절반만 맞는다.

| 증상 | 원인 | 켜는 곳 |
|---|---|---|
| 상품에 N배송 배지가 안 뜬다 | 네이버 **N배송 이용 권한** 미신청 | 판매자센터 N배송 > 권한 관리 > [N배송 신청하기] |
| 파스토 FMS 로 주문이 안 들어온다 | **상품마다** 네이버 풀필먼트 '설정함'이 안 됨 | 상품관리 > 상품 수정 > 네이버 풀필먼트 = 설정함 |
| N배송 재고가 0 으로 나온다 | **SKU 정보 미입력** (입력하지 않은 SKU 는 재고 집계에서 통째로 빠진다) | SKU·재고 > SKU 정보 > 미입력 탭 |

- **풀필먼트를 주문이 들어온 뒤에 켜면 그 주문은 소급 수집되지 않는다.** 이미 들어온 주문은 파스토에서 수기 출고로 처리한다
- **바코드는 SKU 를 처음 등록한 뒤에는 수정할 수 없다.** 입력 전에 파스토 FMS 의 상품 바코드와 한 글자씩 대조한다
- 판매자센터에서 판매자 유형을 고르고 [다음] 을 누르면 **새 스토어가 개설**된다. 로그인 세션이 스토어 없는 커머스 ID 로 바뀌어 `/sellers/join` 화면으로 튀면 누르지 말고 다시 로그인한다

## 1. 셋업 순서 (파스토 가이드 + 실측)

| 순서 | 어디 | 무엇 | 판정 |
|---|---|---|---|
| 1 | 판매자센터 N배송 > 권한 관리 | [N배송 신청하기] 제출 | 화면의 "N배송 이용 권한이 없습니다" 배너가 사라지고 "적용 중인 페널티 없음"이 뜬다. 페널티 0건은 권한 박탈이 아니라 미신청이라는 뜻이다 |
| 2 | 스토어관리 > 네이버 서비스 연결 > 풀필먼트 | 파스토 선택 + 약관 | 승인은 최대 1영업일, 조건을 충족하면 다음 날 03시에 자동 승인된다 |
| 3 | 커머스 API센터 API 관리 | 상품·주문 API 대행사 = 파스토 | 파스토 FMS 쇼핑몰 연동 화면에 "풀필먼트 연동" 배지가 뜬다 |
| 4 | SKU·재고 > SKU 생성·상품 연결 | 파스토 상품과 같은 바코드로 SKU 생성, 상품-SKU 연결 | 연결현황 건수 = 판매 옵션 수 |
| 5 | SKU·재고 > SKU 정보 | **미입력 0건** 만들기(필수값 전부) | SKU별 재고수량 건수 = SKU 전체 건수 |
| 6 | 상품관리 > 상품 수정 (상품마다) | 네이버 풀필먼트 = 설정함 → 저장 | 새 주문이 파스토 미연동내역 없이 FMS 에 들어온다 |
| 7 | 파스토 FMS | 입고 신청 → 입고 완료 | 판매자센터 SKU별 재고수량에 수량이 뜬다 |

## 2. 점검 (N배송이 "안 된다"고 할 때)

위 표를 1~7 전부 잰다. 결과는 표 하나로 남긴다: 구간 · 실측값 · 판정.

- 파스토 쪽: FMS **미연동내역**(주문 수집·송장 연동 실패)이 0 인지, 배정 물류센터, 보관 상품 수
- 네이버 쪽: 권한 관리 배너, SKU 정보 미입력 수, 상품별 풀필먼트 설정 여부
- 파스토에 물어볼 때는 채널톡 상담으로 문의하고 주문내역서 캡처로 답을 받는다. "풀필먼트 미설정 상태로 발주됨" 같은 원인이 그렇게 확인된다

## 3. 계정·권한

| 대상 | 필요한 것 |
|---|---|
| 스마트스토어 판매자센터 | 그 스토어의 통합 매니저 네이버 아이디 |
| 파스토 FMS | 화주 계정(가입 때 받은 화주코드·배정 센터를 메모해 둔다) |
| 남의 스토어를 대신 셋업할 때 | 판매자센터 매니저 초대 + 그쪽 파스토 계정. 1번 권한 신청과 약관 동의는 **대표자 본인 화면**일 수 있으니 미리 요청한다 |

커머스 API 로 할 수 있는 것은 주문 조회와 상품 수정이다. N배송 권한 신청·풀필먼트 약관·SKU 정보 입력은 판매자센터 화면에서만 된다. 커머스 API 앱 발급은 같은 묶음의 `naver-commerce-api-setup` 스킬을 본다.
