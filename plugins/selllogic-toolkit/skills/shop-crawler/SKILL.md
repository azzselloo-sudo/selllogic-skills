# 쇼핑몰 상품 크롤링

```bash
py -3 <프로젝트>/00-core\02-scripts\44-shop-crawler\crawl.py "<목록URL>" -o "<출력폴더>" --sheet
py -3 ... crawl.py "<카페24URL>" "<올영URL>" "<네이버URL>" -o out --sheet   # 여러 몰 한 시트
py -3 ... crawl.py demo                                                      # 파서 자체점검
```

`--sheet` = 사진이 셀에 박힌 구글시트까지 만들고 링크 출력(링크 있는 사람 보기 권한).
컬럼: 썸네일 · **몰** · 브랜드 · 상품명 · 소비자가 · 판매가 · 최종가 · 할인율(%) · 상품링크 · 이미지URL

| 옵션 | 뜻 |
|---|---|
| `--pages N` | 최대 페이지(기본 50). 맛보기는 2 |
| `--no-images` | 목록만, 사진 생략 |
| `--title` | 시트 제목 |

## 몰별 접근 (2026-09-02 실측)

| 몰 | 평범한 요청 | 되는 경로 | 붙는 방식 |
|---|---|---|---|
| **카페24** | 200 | 그대로 | `data-prod-custom`(소비자가)·`data-prod-price`(판매가)·`data-sale-price`(추가할인) 속성을 읽는다. 렌더 텍스트 파싱 불필요 |
| **올리브영** | **403** | `curl_cffi` `impersonate="chrome"` → 200 | `li[criteo-goods]` 블록, `.tx_brand`/`.tx_name`/`.tx_org`/`.tx_cur` |
| **네이버 스마트스토어** | **429·490**, curl_cffi도 로그인 페이지로 튕김 | **실브라우저만**(`naver-profile` `launch_persistent_context`) | DOM 파싱. 내부 API `/i/v2/channels/...`도 429다 |

## 함정 (전부 실제로 밟은 것)

| 증상 | 원인·해법 |
|---|---|
| 시트 사진이 전부 `#REF!` | `=IMAGE()`는 **보는 사람마다** "외부 당사자와 데이터를 주고받으려 합니다 → 액세스 허용"을 눌러야 한다. 전달물에 쓰지 말 것. 이미지가 박힌 xlsx를 드라이브에 올려 구글시트로 변환한다(`to_sheet`가 그렇게 한다) |
| 네이버 판매가가 3,000원 | 카드 텍스트 순서로 금액을 고르면 **배송비**를 집는다. 정가는 `<del>`, 판매가는 카드에서 **글자가 가장 큰** 숫자 노드 |
| 네이버 할인율이 가격과 안 맞음 | 옵션 상품은 카드에 찍힌 %가 실제 가격과 어긋난다. %는 버리고 정가·판매가로 계산 |
| 시트 아래가 1000행까지 비어 있는데 서식이 깔림 | xlsx 변환본은 1000행이다. `ws.resize(rows=행수+1)` 먼저 |
| 상품명이 지저분함 | 리스트 본문 상품명엔 쇼핑몰이 넣은 `<span style>`이 섞여 있다. **`img alt`**를 쓴다 |
| 카페24가 아닌 몰에서 0건 | `detect()`는 카페24를 기본값으로 둔다. 0건이면 그 몰 어댑터를 새로 붙여야 한다는 신호 |
| 크롬이 `TargetClosedError` | 같은 프로필을 다른 크롬이 잡고 있다. 그 크롬을 닫거나 프로필 사본으로 |

## 새 몰 붙이기

`crawl.py`에 함수 하나 + `detect()`에 한 줄. 반환은 `blank(몰이름, 상품명=..., 소비자가=..., 판매가=..., 최종가=..., 상품링크=..., 이미지URL=...)` 딕셔너리 리스트, `product_no` 키만 추가로 채운다. 이미지 다운로드·엑셀·시트는 공통이라 손댈 게 없다.

붙이기 전 **판별부터** 한다.

```bash
curl -s -A "Mozilla/5.0 ... Chrome/131.0.0.0 Safari/537.36" "<URL>" -o x.html -w "HTTP %{http_code} size=%{size_download}\n"
grep -o 'anchorBoxId_[0-9]*' x.html | head -3     # 나오면 카페24
```
403·429면 `curl_cffi impersonate="chrome"` → 그래도 막히면 실브라우저. Shopify는 `<도메인>/products.json?limit=250`이 대개 열려 있다.

## 하지 않는 것

- 로그인 뒤 회원가·재고는 긁지 않는다(약관 위반)
- 요청 간격(카페24 0.7초·올영 0.8초)을 줄이지 않는다
- 긁은 상품사진을 자사 상세페이지에 그대로 쓰지 않는다. **경쟁 분석·가격 비교용**이 기본 용도이고, 다른 용도를 말하면 그 자리에서 짚는다

## 전달

시트 링크 그대로 준다. 로컬 경로·md 금지. 사진 원본이 필요하면 `images/` 폴더를 압축해 드라이브 링크로.
